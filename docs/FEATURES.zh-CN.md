# 在线监测、批量管理与版本更新

## 1. 设备在线状态

主页的设备表显示活动连接、邻居可达状态和最近观察时间。有活动连接或 REACHABLE 邻居显示“有连接／可达”；120 秒内观察过的设备显示“近期可达”。FAILED/INCOMPLETE 显示“探测未达”，其他情况为“未确认”。STALE 邻居和 DHCP 租约不能单独证明在线，也不主动 ping 手机。

## 2. 出口变化提醒

每组第一次成功出口检测建立确认基线；后来成功检测的出口不同会在主页标红，保留前后 IP 和时间。失败检测不会抹掉上次成功出口。点击“确认当前出口”才更新基线，服务器会检查点击时的 IP 是否仍为最新值。本功能不切换节点，不发送邮件、消息或额外桌面通知。

## 3. 搜索与筛选

设备表和节点卡片共用搜索、节点、地区标签、在线状态和异常筛选。可搜索名称、IP、MAC 或节点名；刷新不会清除筛选条件。地区标签依据节点名称识别，例如纽约为美国、巴黎为法国，不是出口 IP 地理定位结果。

## 4. 健康记录

独立的 `phone-panel-monitor` 服务默认每 15 秒采样。每组默认至少间隔 900 秒执行一次 DNS/HTTPS 检测；每轮只检测一个到期分组，避免并发洪峰。分组较多或链路缓慢时实际间隔会延长。每组保留最近 96 次检测，卡片显示最近 24 次趋势和通过率。

保存 DNS/出口结果、分别耗时、错误分类和出口变化记录，不保存代理密码、完整连接内容或 curl 原始错误。身份为节点名称和 DNS/SOCKS 端口；更换身份会重新建立历史基线。

## 5. 设备流量

使用单独的 `inet phone_panel_stats` nftables 表，分别在 prerouting/postrouting 统计受管 IPv4 地址的路由器收发字节。链只计数，不包含 drop、redirect、tproxy 或节点切换。设备改名不清空统计，同 IP 换成另一 MAC 会重新开始。

显示每秒速率、当天和本月上下行累计。当天默认达到 10240 MiB，或采样速率达到 50 Mbps 时提醒；阈值可在设置页调整。累计保留 35 天日桶和 13 个月桶，按路由器日期、采样时刻归账。采样跨日、较长停采间隔和硬件/流量卸载可能造成日分摊或转发计数不完整；不包含手机外部 IPv6，不作为账单计费依据。

从启用监测开始累计，不回填历史。普通采样写入 `/tmp/phone-panel`，约每 5 分钟检查点写入 `/etc/phone-dns/state/traffic.yaml`，正常停止也会保存；突然断电可能丢失最近约 5 分钟。监测停止但内核计数器仍存在时，可在恢复后补记累计字节，不伪造实时速率。重启计数器或路由器不会产生负流量。

## 6. 批量添加

管理维护页点击“读取可选设备”，从未纳管的有效 DHCP 租约勾选 1～32 台并选择节点。冲突租约会标记并禁选；名称可修改。预览会重新检查全部 MAC/IP、静态租约、来源规则与节点，再检查批内重复 IP/MAC。

改动表单会使旧预览失效；应用时还会检查配置版本。整批共用一个作业、一个快照和一次配置生成/代理重启。校验不通过则整批停止，应用失败走已有恢复流程。仅显示可用租约不等于能证明离线静态 IP 没被占用。

## 7. 故障诊断

节点卡片“诊断与记录”会执行本次检测，并分别列出 DNS 入口、SOCKS 入口、节点绑定、DNS 实际解析和 HTTPS 出口。分类用于定位阶段；例如代理协商失败可能涉及认证或上游，不把超时直接认定为密码错误。UDP 业务明确显示未验证，DNS/HTTPS 通过不能证明全部 UDP 可用。

## 8. 版本、升级与程序恢复

管理维护页显示部署提交和恢复记录。检查更新只访问固定仓库 `593663247/openclash-phone-panel`，核对 main、相对当前版本可快进及该提交的 CI 工作流成功。不会定时自动升级，也不接受任意下载地址或 shell 命令。

点击“备份并升级”创建持久任务；工作进程再次核对目标提交和 CI，下载对应的 HTTPS 源码归档。归档检查单一根目录、路径穿越、链接、文件数量及展开大小。暂存语法和依赖检查通过后先做本地完整备份，再保存程序恢复快照，原子替换程序文件。

升级不覆盖当前 DHCP、节点源配置、映射、DNS 配置或用户钩子；只重启监测服务，不主动重启 OpenClash。安装后检查状态、设备数量、原先正常的监听/保护和网络进程；失败会尝试恢复原程序。维护记录保留结果，详细日志仅在路由器本地。

“恢复所选程序版本”只恢复程序和版本标记，保留后来新增/修改的设备配置；执行前再次保留当前程序快照。旧版本可能没有这些新功能。完整配置恢复仍按 MAINTENANCE.md 手动执行；程序恢复不是所有运行态的通用事务回滚。

所有写操作依赖原 LuCI 登录与 POST CSRF 校验。健康、流量、出口记录、任务和备份包含私密设备信息，只保存在路由器，不上传 GitHub。

## 运行命令

```sh
/etc/init.d/phone-panel-monitor status
/etc/init.d/phone-panel-monitor restart
ruby /etc/phone-dns/releases.rb check
# 原始源码目录的 root 安装入口；不由网页接收路径：
# ruby /etc/phone-dns/releases.rb install-local SOURCE_DIRECTORY FULL_COMMIT_SHA
```

设置页可禁用监测或调整采样、检测间隔和流量提醒阈值。设置中关闭监测后会移除自有流量计数表并停止后台检测，累计记录保留；仅停止/重启服务则保留内核计数器供恢复。关闭监测不解除原有固定出口、防直连或 DNS 接管规则。
